=======
Ai3 FAQ
=======

:Extension key:
    ai3_faq

:Package name:
    wegewerk/ai3_faq

:Version:
    |release|

    en

:Author:
    wegewerk GmbH

:Rendered:
    |today|

----

Ai3 FAQ is a TYPO3 extension that adds an AI-powered **Page FAQ**
content element. Editors can generate frequently asked questions and answers
based on the content on the current page, using the **ZAK-AI REST API**.

The generated FAQ is a copy of the accordion element provided by the bootstrap package.

It is part of the *Ai3 Suite* and requires :composer:`wegewerk/ai3_core`.
